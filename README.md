# Ghost Mode AI 👻

**Ghost Mode AI** is an iOS mobile application designed to help users navigate breakups, maintain no-contact goals, build healthy habits, and focus on personal growth.

The app combines AI-powered coaching, journaling, and progress tracking to support users throughout their personal development journey.

## Features

- **AI Coach:** AI-powered conversations offering encouragement, guidance, and emotional support.
- **No-Contact Streak Tracker:** Track progress and celebrate milestones throughout the no-contact journey.
- **Personal Journaling:** Record thoughts, emotions, and reflections.
- **Milestone Achievements:** Celebrate progress with achievements extending beyond 90 days.
- **Progress Tracking:** Encourage consistency, discipline, and personal growth.
- **User Authentication:** Account registration and login functionality.

Ghost Mode AI was developed using React Native and Expo, with AI-assisted development tools.

The project involved:

- Implementing user authentication.
- Developing journaling and streak-tracking features.
- Debugging and improving the user experience.
- Testing through Expo Go and Apple TestFlight.
- Preparing and submitting the application for App Store review.
